Privacy Policy

Last updated: October 2026

Sam OpenClaw Workmail is a private personal productivity application operated for the account owner's own use.

Google user data accessed

The application may access Gmail message and thread information needed to review email, search correspondence, classify messages, and create Gmail drafts. It may also access Google Calendar information when calendar functionality is explicitly authorized.

How data is used

Google user data is used only to provide requested email and calendar functions for the account owner.

Storage

OAuth credentials and application state are stored on systems controlled by the application owner. OAuth credentials are not published through this website.

Sharing

Google user data is not sold and is not used for advertising. This application is not offered as a public service to third parties.

Email sending

The application may create Gmail drafts but does not automatically send email. Sending remains under the account owner's control.

Revoking access

The account owner may revoke the application's Google account access through Google Account security settings.
